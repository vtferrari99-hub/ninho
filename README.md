# Ninho

Cozy game estilo tamagotchi com dragões (Android, Kotlin, sem dependências além do SDK).

- Um dragão por vez; cada raridade cresce num ritmo (Raro = 2× mais devagar que Comum).
- Fases: ovo → bebê → criança → adolescente → adulto → ancião.
- Refeições: café da manhã (6h–10h), almoço (11h–14h), jantar (18h–21h).
- Dorme das 22h às 6h; o céu acompanha o relógio do celular.
- Toque: carinho · dois toques: pulinho · segurar: abraço · esfregar: cafuné · toque no chão: ele vai até lá.

O APK de teste é gerado pelo GitHub Actions e fica no branch `builds`.
